## Reading guide for Python fundamentals

This project has become a bit of a mess with duplicated content, so this reading guide may be useful:

+ If trying to get up to speed with Python, start with [Exercises.md](./00_basic-python-workout/EXERCISES.md). You can practice those exercises on your own, or review the solutions in [01: Getting up to speed](00_basic-python-workout/projects/01_getting_up_to_speed/README.md). Please note that those exercises rely on `uv` but the only thing you need to know about `uv` at that point is to run the programs with `uv run <exercise>.py`.

+ If you're comfortable with the exercises, you might want to take a look at [02: Managing modern Python projects](00_basic-python-workout/projects/02_managing_projects/README.md). That section contains a distilled introduction to `uv`.

+ If you don't know about [pytest](https://docs.pytest.org/en/stable/), it's highly encouraged that you go through [03: pytest basics](00_basic-python-workout/projects/03_pytest_test_basics/README.md).

+ Next, you should tackle [04: Basics deep-dive labs](00_basic-python-workout/projects/04_basics_deep_dive_labs/README.md). This is similar to the Exercises section aforementioned, but the examples are more contrived and will let you exercise your Python skills in a deeper way.

+ The notebooks in [Basics: Deep Dive](03_basics-deep-dive/) are also a good source of detailed information on modern Python if you're looking for specific details about a particular topic. Many of the exercises and labs are taken from those notebooks.

I would not recommend following any of the other notebooks in this section, as they may contain outdated (especially with respect to tooling and project management) or duplicated information (that can be found in the bullet points above).
