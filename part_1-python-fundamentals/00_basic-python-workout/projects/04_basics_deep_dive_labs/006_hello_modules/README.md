# 006: Hello, modules!
> Illustrate the basics of modules in Python

## Solution

In the exercise, you need to define a file `mymath.py` in which you'll write the functions and variables that could be consumed via import.

The program also includes a test to validate the functions defined in the module.

You can run the tests with `uv run pytest`.

## Running the program

See [README.md](../README.md#006-hello-modules) for full details.

You can run the application with:

```bash
uv run main.py
```
