# 01: hello, pytest
> basics of pytest: setting up shop, basic pytest config, and running your first test

See [README.md](../README.md#01-hello-pytest) for full details.

You can run the application with:

```bash
uv run main.py
```

And you can run your tests from the command line with:

```bash
uv run pytest
```

You can also run the tests from your IDE.
