# Azure Administration
> https://learn.microsoft.com/en-us/plans/50nrtozg28d354

Azure administrators have subject matter expertise implementing, managing, and monitoring an organization's Microsoft Azure environment.

Responsibilities for this role include implementing, managing, and monitoring identity, governances, storage, compute, and virtual networks in a cloud environment, plus provision, size, monitor, and adjust resources.

Azure administrators are certified with the Exam AZ-104.

It contains the following trainings:

1. [AZ-104: Prerequisites for Azure administrators](https://learn.microsoft.com/en-us/training/paths/az-104-administrator-prerequisites/?ns-enrollment-type=Collection&ns-enrollment-id=xe27iz5er6zn28)

2. [AZ-104: Manage identities and governance in Azure](https://learn.microsoft.com/en-us/training/paths/az-104-manage-identities-governance/?ns-enrollment-type=Collection&ns-enrollment-id=xe27iz5er6zn28)

3. [AZ-104: Implement and manage storage in Azure](https://learn.microsoft.com/en-us/training/paths/az-104-manage-storage/?ns-enrollment-type=Collection&ns-enrollment-id=xe27iz5er6zn28)

4. [AZ-104: Deploy and manage Azure compute resources](https://learn.microsoft.com/en-us/training/paths/az-104-manage-compute-resources/?ns-enrollment-type=Collection&ns-enrollment-id=xe27iz5er6zn28)

5. [AZ-104: Configure and manage virtual networks for Azure administrators](https://learn.microsoft.com/en-us/training/paths/az-104-manage-virtual-networks/?ns-enrollment-type=Collection&ns-enrollment-id=xe27iz5er6zn28)

6. [AZ-104: Monitor and back up Azure resources](https://learn.microsoft.com/en-us/training/paths/az-104-monitor-backup-resources/?ns-enrollment-type=Collection&ns-enrollment-id=xe27iz5er6zn28)

7. [Microsoft 365 Certified: Administrator Expert - Certifications](https://learn.microsoft.com/en-us/credentials/certifications/m365-administrator-expert/?ns-enrollment-type=Collection&ns-enrollment-id=xe27iz5er6zn28)
