# Create agentic AI solutions by using Azure AI Foundry (1)
> Notes from https://learn.microsoft.com/en-us/plans/op8ugtzy32mz

## Milestone 1

Learn how to describe the core features and capabilities of Azure AI Foundry, provision and manage Azure AI resources, create and manage AI projects, and determine when to use Azure AI Foundry.

### Module 1
> [Plan and prepare to develop AI solutions on Azure](https://learn.microsoft.com/en-us/training/modules/prepare-azure-ai-development/?source=docs)

Learning objectives:

+ Identify common AI capabilities that you can implement in applications.
+ Describe Azure AI Services and considerations for using them.
+ Describe Azure AI Foundry and considerations for using it.
+ Identify appropriate developer tools and SDKs for an AI project.
+ Describe considerations for responsible AI.

### Module 2
> [Develop and AI app with Azure AI Foundry SDK](https://learn.microsoft.com/en-us/training/modules/ai-foundry-sdk/)

Learning objectives:

+ Describe capabilities of the Azure AI Foundry SDK.
+ Use the Azure AI Foundry SDK to work with connections in projects.
+ Use the Azure AI Foundry SDK to develop an AI chat app.

## Milestone 2

Learn how to use RAG in Azure AI Foundry with Azure AI Search using Azure AI Foundry SDK.

### Module 1
> [Develop a RAG-based solution with your own data using Azure AI Foundry](https://learn.microsoft.com/en-us/training/modules/build-copilot-ai-studio)

Retrieval augmented generator (RAG) is a common pattern used in generative AI solution to ground prompts with your data. Azure AI Foundry support for adding data, creating indexes, and integrating them with GenAI models to help you build RAG-based solutions.

Learning objectives:

+ Identify the need to ground your language model with Retrieval Augmented Generation (RAG).
+ Index your data with Azure AI Search to make it searchable for language models.
+ Build an agent using RAG on your own data in the Azure AI Foundry portal.
