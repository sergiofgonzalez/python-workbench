# 004: Cognee doc demo using AzureOpenAI
> A Cognee doc demo with AzureOpenAI models

## Project description

The demo illustrates how to query a document using Cognee.

## Running the program

Configure the `.env` following the template given in `.env.example`.

You can run the application with:

```bash
uv run python main.py
```

## Project management

This project is managed using `uv`.
