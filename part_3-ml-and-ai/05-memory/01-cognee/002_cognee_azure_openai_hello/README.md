# 002: Hello, Cognee using AzureOpenAI
> Illustrates how to get started with Cognee with AzureOpenAI models

## Project description

Cognee quickstart with AzureOpenAI models.

## Running the program

Configure the `.env` following the template given in `.env.example`.

You can run the application with:

```bash
uv run python main.py
```

## Project management

This project is managed using `uv`.
