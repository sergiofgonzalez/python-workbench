# 001: Hello, Cognee (using LiteLLM)
> Illustrates how to get started with Cognee with LiteLLM (requires monkey-patching)

## Project description

Cognee quickstart with LiteLLM models.

## Running the program

Configure the `.env` following the template given in `.env.example`.

You can run the application with:

```bash
uv run python main.py
```

## Project management

This project is managed using `uv`.
